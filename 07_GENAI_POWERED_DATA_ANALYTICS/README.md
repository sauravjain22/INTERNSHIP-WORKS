# GenAI Powered Data Analytics Job Simulation

## Project Overview

This project was completed as part of the GenAI Powered Data Analytics Job Simulation.

The project focuses on using data analytics and predictive modeling techniques to analyze customer delinquency risk and translate analytical findings into clear business recommendations.

The workflow covers exploratory data analysis, risk profiling, predictive modeling planning, and business reporting.

## Project Objectives

- Analyze and understand the provided delinquency dataset.
- Perform exploratory data analysis and identify important patterns.
- Profile customer risk and delinquency-related factors.
- Develop a structured plan for predictive modeling.
- Translate analytical findings into actionable business insights.
- Present results through professional reports.

## Dataset

The project uses:

`Delinquency_prediction_dataset.xlsx`

The dataset contains information used to analyze delinquency and customer risk patterns.

## Project Tasks

### Task 1 — EDA & Risk Profiling

Performed exploratory data analysis to understand the dataset and identify patterns related to delinquency risk.

Key activities included:

- Data inspection and validation
- Understanding dataset structure
- Analysis of variables and distributions
- Identification of risk-related patterns
- Risk profiling
- Generation of analytical insights

Notebook:

`Notebooks/Task_1_EDA_Risk_Profiling.ipynb`

Report:

`Reports/EDA_SummaryReport.docx`

### Task 2 — Predictive Model Plan

Created a structured predictive modeling plan for delinquency prediction.

The plan covers:

- Problem definition
- Target variable
- Feature considerations
- Data preparation
- Model development approach
- Model evaluation
- Business application of predictions

Report:

`Reports/Task_2_Predictive_Model_Plan.docx`

### Task 3 — Business Report

Translated the analytical findings into a business-oriented summary.

The report focuses on:

- Key findings
- Business implications
- Risk-related insights
- Recommendations
- Practical application of the analysis

Report:

`Task_3_Business_Report/Business_Summary_Report.docx`
