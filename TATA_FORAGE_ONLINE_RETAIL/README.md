# Forage – Online Retail Analysis

## Overview

This project was completed as part of my data analytics learning journey through **Forage**.

The project focuses on analysing an **Online Retail** dataset using **Microsoft Power BI** to transform raw transactional data into meaningful business insights through data preparation, analysis, visualisation and an interactive dashboard.

The objective was to understand customer and sales behaviour and present the findings in a business-friendly format that can support data-driven decision-making.

---

## Project Objective

The main objectives of this project were to:

- Analyse online retail transaction data
- Understand sales and customer behaviour
- Identify important business trends and patterns
- Transform raw data into meaningful information
- Build an interactive Power BI dashboard
- Present insights in a clear and decision-oriented format

---

## Dataset

The project uses an **Online Retail transactional dataset** containing information related to retail purchases.

The data represents individual transactions and can be used to analyse areas such as:

- Products
- Customers
- Quantity purchased
- Transaction values
- Invoice information
- Transaction dates
- Countries / geographic information

---

## Project Workflow

### 1. Data Understanding

The dataset was first explored to understand:

- Available fields
- Transaction structure
- Customer information
- Product information
- Sales-related variables
- Date and geographic information

### 2. Data Preparation

The data was prepared for analysis in Power BI by examining and handling issues within the transactional dataset.

The preparation process focused on making the data suitable for reliable analysis and visualisation.

### 3. Data Analysis

The analysis focused on understanding:

- Sales performance
- Customer behaviour
- Product performance
- Transaction patterns
- Geographic distribution
- Trends over time

### 4. Power BI Dashboard

An interactive dashboard was developed using **Microsoft Power BI**.

The dashboard converts the underlying transactional data into visual information that allows users to explore the business performance from different perspectives.

---

## Dashboard

The final deliverable is a Power BI dashboard created using the Online Retail dataset.

### Dashboard capabilities

The report allows users to explore the data through interactive visualisations and filtering.

It is designed to help answer questions such as:

- How are sales performing?
- Which products contribute most to performance?
- How does customer activity vary?
- Which locations contribute to sales?
- How does performance change over time?
- What patterns can be identified from the transaction data?
