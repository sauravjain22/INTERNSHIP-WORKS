# Met Office Careers: Data Science and Meteorological Phenomenon

## Project Overview

This project was completed as part of the **Springpod Met Office Careers: Data Science and Meteorological Phenomenon** virtual work experience programme.

The project explores the **Urban Heat Island (UHI) effect** by analysing temperature differences between St James's Park, located in central London, and Northolt, on the outskirts of the city.

The analysis was conducted using Microsoft Excel, focusing on identifying relationships between temperature differences, time of day, month of the year, wind speed, and cloud amount.

## Project Objectives

- Understand and inspect meteorological data.
- Identify missing and unusual values.
- Explore temperature differences between an urban location and its surroundings.
- Analyse how the Urban Heat Island effect varies by hour and month.
- Investigate the relationship between wind speed, cloud amount, and temperature differences.
- Interpret findings and communicate conclusions using Excel.

## Tools and Technologies

- Microsoft Excel
- Data filtering and inspection
- Excel formulas and averages
- Data visualization and line charts
- Exploratory Data Analysis (EDA)

## Key Findings

- **Time of day:** The temperature difference varied by approximately 1.03°C across the hours of the day.
- **Month of year:** The temperature difference varied by approximately 0.38°C across the months.
- **Wind speed:** The temperature difference varied by approximately 2.32°C across the wind-speed averages examined.
- **General relationship:** The average temperature difference generally decreased as wind speed increased.
- **Data quality:** The dataset contained `NA` entries, highlighting the importance of identifying and handling unavailable observations before analysis.

These findings describe relationships in the supplied dataset and do not, by themselves, establish causation.
