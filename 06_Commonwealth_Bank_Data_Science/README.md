# Commonwealth Bank Data Science Job Simulation

This project was completed as part of the **Commonwealth Bank Data Science Job Simulation** on **Forage**.

The simulation provided practical exposure to data analysis, data anonymisation, social media analytics, database design, and business-focused data science.

The tasks were based around a business scenario involving **Commonwealth Bank (CommBank)** and the use of structured and unstructured data to generate useful business insights.

Internship / Job Simulation Overview

The Commonwealth Bank Data Science Job Simulation on Forage was designed to provide practical exposure to several stages of a data-focused business workflow.

The simulation covered:

Data aggregation and analysis
Data anonymisation
Social media data analysis
Data analysis proposal development
Database design
Business insight generation
Data privacy and integrity concepts

The work focused on understanding how data can be transformed from raw records into structured information that can support business analysis and decision-making.

Tasks Completed
Task 1 — Data Aggregation and Analysis

The first task focused on analysing supermarket transaction data using Microsoft Excel.

The objective was to answer business questions by aggregating transaction records using multiple conditions.

Key activities included:

Using SUMIFS for conditional aggregation
Calculating product quantities
Calculating total transaction amounts
Filtering transaction records using multiple criteria
Organising results into a structured analysis sheet
Interpreting aggregated results from a business perspective

This task provided practical experience with data aggregation and business-oriented analysis using Excel.

Task 2 — Data Anonymisation

The second task focused on protecting sensitive customer information while retaining useful information for analysis.

The dataset contained customer-related information such as names, usernames, addresses, emails, dates, salary information, and credit-card details.

The anonymisation process included:

Removing unnecessary identifying fields
Masking usernames and email addresses
Replacing names and addresses with fictional values
Adding noise to selected dates
Categorising age and salary
Tokenising selected fields
Masking credit-card numbers and security codes

This task provided practical exposure to data privacy, anonymisation, and responsible handling of sensitive information.

Task 3 — Propose Data Analysis Approaches

The third task focused on a curated Commonwealth Bank social media dataset.

The objective was to propose ways that InsightSpark could use social media data related to CommBank to extract useful insights and enrich its database.

The analysis considered:

Topic analysis
Engagement analysis
Sentiment analysis
Customer-support analysis
Trend analysis
Marketing insights
Product insights
Risk and security insights

The work examined information such as:

Post topics
Post text
Engagement metrics
Sentiment
Customer intent
Content formats
Scam and security-related discussions

The task also considered how social media API data could provide structured information such as post text, timestamps, engagement metrics, replies, reposts, mentions, and other metadata.

Task 4 — Designing a Database

The fourth task focused on designing a structured relational database for storing Commonwealth Bank social media information.

The proposed database was designed to store:

CommBank posts
User replies
User quote retweets
Direct mentions
Engagement information
Hashtags

The proposed database contains six tables:

Users
Posts
Post_Engagement
Mentions
Hashtags
Post_Hashtags

The database design includes:

Primary keys
Foreign keys
One-to-many relationships
One-to-one relationships
Self-referencing relationships
Many-to-many relationships
Data integrity considerations
Reduction of redundant information

The database was designed and documented rather than implemented as an actual database, as the task required a proposed database structure and text submission.

Key Learning Outcomes

This simulation provided practical exposure to how data can be prepared, analysed, protected, structured, and interpreted for business use.

The overall workflow can be summarised as:

Raw Data
   ↓
Data Preparation
   ↓
Data Analysis
   ↓
Business Insights
   ↓
Data Structure / Database Design
   ↓
Business Decision Support

The simulation also demonstrated that data science involves more than machine learning. Practical data science work can involve data analysis, data privacy, business understanding, social media analytics, database concepts, and communication of insights.
