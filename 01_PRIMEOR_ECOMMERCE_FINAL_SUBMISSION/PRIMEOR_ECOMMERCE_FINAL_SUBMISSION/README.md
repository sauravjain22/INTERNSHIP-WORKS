Primeor Solutions – E-Commerce Data Analytics

Project Overview

This project was completed as part of an E-Commerce Data Analytics internship at Primeor Solutions.

The objective was to clean, analyze, and visualize an e-commerce dataset and convert the raw data into meaningful business insights.

The project covers the complete analytics workflow, from data cleaning and exploratory analysis to SQL analysis, Power BI visualization, and a final business insights report.


Project Workflow

Raw Dataset
   ↓
Data Cleaning
   ↓
Excel Analysis
   ↓
SQL Analysis
   ↓
Power BI Dashboard
   ↓
Business Insights Report


Dataset

The original dataset contained approximately 51,270 records and 21 columns.

The data included information related to:

- Orders
- Customers
- Products
- Categories
- Regions
- Markets
- Sales
- Profit
- Discounts
- Dates
- Shipping information


Data Cleaning

The raw dataset was cleaned and prepared before performing the analysis.

The cleaning process included:

- Identifying and removing duplicate records
- Handling missing values
- Standardizing inconsistent text values
- Removing unnecessary spaces
- Converting inconsistent date formats
- Identifying invalid numerical values
- Checking and correcting data types
- Preparing the cleaned dataset for analysis


Excel Analysis

Excel was used for data cleaning, exploratory analysis, and initial business analysis.

The analysis included:

- PivotTables
- Summary calculations
- Sales analysis
- Profit analysis
- Category analysis
- Regional analysis
- Monthly trends
- Charts and visualizations


SQL Analysis

The cleaned dataset was imported into SQL for structured business analysis.

The SQL queries were used to analyze:

- Top-selling products
- Top customers
- Sales by category
- Sales by region
- Product performance
- Profitability
- Business-level aggregations


Power BI Dashboard

An interactive Power BI dashboard was created to provide a consolidated view of e-commerce performance.

Key metrics included:

- Total Sales: approximately 12.64M
- Total Profit: approximately 1.47M
- Average Discount: approximately 0.14
- Unique Orders: approximately 25K

The dashboard covered:

- Sales by region
- Sales by market
- Category performance
- Monthly sales trends
- Top products
- Top customers
- Profit by subcategory
- Regional performance

Interactive slicers were also used to allow users to explore the data across different business dimensions.


Business Insights

The analysis focused on understanding:

- Which categories and products generated the highest sales
- Which regions and markets contributed most to overall performance
- How sales changed over time
- Which products and customers had significant business contribution
- How profitability varied across subcategories
- The impact of discounts on sales and profitability
